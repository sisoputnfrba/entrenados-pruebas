# EntrenadOS - Suite de Tests y Jobs

Este repositorio centraliza los archivos de prueba (Jobs) y los scripts de configuracion necesarios para validar el desarrollo del Trabajo Practico EntrenadOS de la catedra de Sistemas Operativos (UTN FRBA, 2C2026).

-----

## Organizacion del Repositorio

El repositorio esta organizado siguiendo los puntos de control del cronograma de entregas. A medida que avancemos en la cursada, liberaremos nuevas pruebas en sus respectivas carpetas:

  - /checkpoints/: Contiene las pruebas para los controles obligatorios parciales.
      - /checkpoint\_1/: Conexiones y Serializacion.
      - /checkpoint\_2/: Planificacion y Ejecucion Basica.
      - /checkpoint\_3/: Memoria, Paginacion y Servicios.
      - /checkpoint\_4/: Filesystem y Persistencia.
  - /entregas\_finales/: Casos de prueba de integracion final.

-----

## Como usar estos archivos?

Cada archivo dentro de las carpetas de checkpoints representa un Job que debe ser procesado por el sistema.

1.  Formato: Los archivos tienen extension .asm (ensamblador) para facilitar el resaltado de sintaxis en GitHub.

2.  Configuracion: Cada carpeta de pruebas incluira, cuando sea necesario, archivos config de ejemplo.
